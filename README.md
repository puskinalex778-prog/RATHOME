# Крыски дома — 3D-симулятор декоративных домашних крыс для Android

Уютная интерактивная 3D-игра о заботе, приручении и жизни декоративных домашних крыс для детей и взрослых. Работает полностью **офлайн** на Android (через Capacitor + WebGL2/Three.js) и в браузере.

## Как собрать установочный APK через GitHub Actions (без установки Android Studio)

1. Создайте новый репозиторий на GitHub (публичный или приватный).
2. Загрузите содержимое этой папки в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "Крыски дома: первая версия 3D-игры"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в вашем репозитории на GitHub.
4. Автоматически запустится workflow **«Build Android APK (Крыски дома)»** (его также можно запустить вручную кнопкой **Run workflow**).
5. После завершения сборки откройте запуск workflow и скачайте артефакт **KryskiDoma-APK** (внутри готовый файл `KryskiDoma-android.apk`).
6. Перенесите `KryskiDoma-android.apk` на Android-смартфон и откройте для установки (при запросе разрешите установку из этого источника).

## Локальный запуск для проверки на ПК

```bash
npm install
npm run dev
```
Откройте в браузере адрес, который покажет Vite (обычно `http://localhost:5173`).

## Автотесты и локальная сборка Android (если установлен Android SDK + JDK 21)

```bash
npm test
npm run cap:sync
cd android
./gradlew assembleDebug
```
Готовый APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Основные особенности игры
- **Интерактивная 3D-сцена** (Three.js): просторная 2- и 3-ярусная клетка со сплошными полками и безопасными лесенками, защищённый игровой манеж, 6 тем оформления комнаты, камера с вращением, приближением, режимом на уровне питомца, слежением и фоторежимом без интерфейса.
- **21 готовый окрас + конструктор**: белая с серой полоской по спине (варианты с белой головой и серой шапочкой), полностью серая, белая с тёмными/красными глазами, чёрная, капюшонная, пятнистые, беркшир, голубовато-серая, агути, бежевая, кремовая, шоколадная, сиамская, гималайская, серебристая и др., плюс ушки (обычные/дамбо), шерсть (гладкая/рекс), предпросмотр взрослого вида, обычный и творческий режим окрасов.
- **Вступительная 3D-кат-сцена**: выбор и имена первой однополой пары малышей, приезд в переноске и заселение в клетку (можно пропустить).
- **8 индивидуальных характеров и живое поведение**: ходьба, лазание по лесенкам, умывание, стойка на задних лапках, еда лапками, сон в гамаке и домике, совместный сон, взаимный груминг, дружеская возня, добровольный подход к ладони, поглаживание пальцем.
- **Мини-игры, обучение, бережная уборка, магазин и обустройство** с проверкой пересечений и безопасной высоты.
- **Комфортный режим, локальные автосохранения + резервная копия JSON** и отдельные переключатели разведения (выключено по умолчанию), старения и естественной смерти.
